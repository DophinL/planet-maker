# Security policy

## Supported version

Security fixes target the latest commit on `main`.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature instead of a public issue. Include reproduction steps, affected browsers, and the practical impact. You should receive an acknowledgement within seven days.

Planet Maker has no backend and stores project state in the browser, but imported images, GLBs, and project JSON are still untrusted input. Do not include private assets in a public reproduction.
